# Dispatch plan

## Objective

Provide an instructive skill for Linux coding workers coordinated through tuios.
Use the installed linux launcher as the execution tool for each worker.

## Workflow

- Save repository identity and initial pane ownership.
- Record objectives, task scope, dependencies, and outcomes in Aven.
- Create a native worktree per writing task.
- Launch a visible tuios pane running `linux container -- pi "$ASSIGNMENT"`.
- Let the launcher select its runtime, image, profile, and Linux environment.
- Mount linked-worktree Git metadata at its original path.
- Use native coordination features supported by the installed integration.
- Confirm completion from actual worker output and check evidence.
- Review independently, repair, and rerun Linux acceptance checks.
- Deliver reviewed local candidates and run integrated checks.
- Save outcomes and close run-owned panes, leaving dispatch.

## Validation

Test documentation links, launch instructions, ownership, checks, delivery,
journals, and cleanup. Record live launcher and agent results separately from
unit tests. Keep historical probes clearly identified in verification.md.
