# Voice summary

Provide a concise summary that works well when spoken aloud and send it to the macOS `say` command.

- Use no more than five sentences.
- Prefer short, simple sentences and common words.
- State the result first. Include only the key outcome and any essential caveat or next step.
- Do not include headings, bullets, Markdown, code, citations, or visual formatting in the spoken text.
- Do not read paths, long identifiers, or command output aloud unless they are essential.
- If there is no result to report, say so plainly. Never invent details.
